# PRD: md-to-pdf-jp

## 目的

Markdown ファイルを入力として、日本語が読みやすい**学術論文に近い体裁**の PDF をローカルで生成する。

## ユーザー

- 技術文書・社内メモ・レポートを PDF で共有したい人
- 日本語の見た目（フォント・行間）をある程度制御したい人

## スコープ（v1）

- CLI で `.md` を指定し `.pdf` を出力する
- 見出し・本文・コード・表・引用・リストをサポート（GitHub Flavored Markdown ベース）
- Web フォント（Google Fonts）で日本語向けタイポグラフィを提供
- オフライン完結は必須としない（初回 PDF 生成時にフォント取得のためネットワーク利用可）

## 非スコープ（v1）

- GUI アプリケーション
- カスタム CSS ファイルの読み込み（将来拡張の余地あり）
- LaTeX 相当の厳密な組版

## 成功指標

- サンプル Markdown から破綻なく PDF が生成される
- 明朝ベースの本文・表題・節見出し・ページ番号など、論文調の視覚的な一貫性が得られる
